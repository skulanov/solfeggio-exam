# Подготовка к экзамену по сольфеджио

Обучающее приложение для подготовки к экзаменам по сольфеджио. Приложение включает в себя интерактивные билеты с аудио-примерами, изображениями и теоретическую базу (ответы на билеты).

---
## ✨ Основные возможности

### 🎫 Интерактивные билеты
Весь экзаменационный материал разбит на удобные билеты. Каждый билет включает в себя разделы с гаммами, ступенями, интервалами и аккордами, соответствующими реальной программе экзамена.

### 🎧 Аудио-тренажер
Слушайте правильное звучание музыкальных элементов прямо в приложении:
- Натуральные, гармонические и мелодические миноры.
- Отдельные ступени и их разрешения.
- Аккордовые последовательности и интервалы.
- Двухголосные примеры и диктанты.

### 🖼️ Визуальные подсказки
Каждый билет сопровождается четкой нотной графикой, что помогает сопоставить услышанное с визуальным представлением нот.

### 📚 Полный справочник теории
Интерактивный раздел «Ответы на билеты» содержит:
- Подробные текстовые пояснения сложных тем.
- Таблицы сравнения интервалов и аккордов.
- Правила построения и разрешения музыкальных элементов.

### 📱 Удобство и дизайн
- **Адаптивность**: Приложение прекрасно работает на смартфонах, планшетах и компьютерах.
- **Интуитивный интерфейс**: Мягкая анимация и классический «академический» дизайн создают рабочую атмосферу.
- **Мгновенный доступ**: Быстрое переключение между билетами и теорией.

---
## 🚀 Технологический стек
Приложение построено на базе передовых технологий:
- **React 18** — для быстрого и отзывчивого интерфейса.
- **Vite** — для надежной сборки.
- **Tailwind CSS** — для чистого и современного оформления.
- **Motion (Framer Motion)** — для плавных визуальных переходов.
- **Lucide Icons** — для понятной навигации.

---
## 📖 Как пользоваться
1. Откройте приложение по ссылке [https://skulanov.github.io/solfeggio-exam/](https://skulanov.github.io/solfeggio-exam/).
2. Выберите нужный билет из списка на главной странице.
3. Изучайте нотную запись и прослушивайте аудио-примеры.
4. Используйте раздел «Ответы на билеты» для повторения теоретического материала.
