# Сольфеджио - Билеты

Обучающее приложение для подготовки к экзаменам по сольфеджио. Приложение включает в себя интерактивные билеты с аудио-примерами, изображениями и теоретическую базу (ответы на билеты).

## Основные возможности

- **Интерактивные билеты:** 5 билетов с гаммами, цепочками ступеней и аккордов, а также одноголосными и двухголосными номерами.
- **Аудио-примеры:** Возможность прослушать каждый элемент билета.
- **Раздел теории:** Полные ответы на билеты с правилами, таблицами и определениями (лады, интервалы, аккорды и т.д.).
- **Адаптивный дизайн:** Удобная работа как на компьютерах, так и на мобильных устройствах.

## Технологии

- **React 19**
- **Vite** (сборка и разработка)
- **Tailwind CSS** (стилизация)
- **Lucide React** (иконки)
- **Motion (Framer Motion)** (анимации)
- **TypeScript**

## Как запустить локально

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте браузер по адресу `http://localhost:3000`.

## Сборка для публикации

Чтобы собрать проект для размещения на хостинге:
```bash
npm run build
```
Готовые файлы появятся в папке `dist/`.
